## 4. 数据转换（jsonl -> alpaca）

在 `/workspace/dog_llm_exec` 新建 `convert_to_alpaca.py`：

```python
import json
from pathlib import Path

src = Path('/workspace/dog_llm_exec/dog_control_dataset.jsonl')
dst = Path('/workspace/dog_llm_exec/dog_control_alpaca.json')

system_prompt = "你是机器狗控制助手。将用户中文命令转换为严格JSON：{\"actions\":[...]}，不要输出解释。"

rows = []
with src.open('r', encoding='utf-8') as f:
    for line in f:
        x = json.loads(line)
        rows.append({
            "instruction": system_prompt,
            "input": x["instruction"],
            "output": x["output"]
        })

with dst.open('w', encoding='utf-8') as f:
    json.dump(rows, f, ensure_ascii=False, indent=2)

print('done:', len(rows), '->', dst)
```

执行：

```bash
python /workspace/dog_llm_exec/convert_to_alpaca.py
```

## 6. LoRA 微调（LLaMA-Factory）

## 6.1 WebUI 方式（最推荐）

启动：

```bash
cd /workspace/LLaMA-Factory
llamafactory-cli webui
```

浏览器打开 WebUI 后配置：

- Model name/path: `Qwen/Qwen2.5-7B-Instruct`
- Stage: `sft`
- Dataset: `dog_control`
- Template: `qwen`
- Finetuning type: `lora`
- LoRA target: `q_proj,k_proj,v_proj,o_proj`
- LoRA rank: `8`
- LoRA alpha: `16`
- LoRA dropout: `0.05`
- Max length: `512`
- Learning rate: `2e-4`
- Epochs: `3`
- Train batch size: `4`
- Grad accumulation: `4`
- Val size: `0.1`
- Save steps: `100`
- Eval steps: `100`
- Plot loss: 开启

点击 Start 开始训练。

## 6.2 CLI 方式（可复现）

```bash
cd /workspace/LLaMA-Factory

llamafactory-cli train \
  --stage sft \
  --model_name_or_path Qwen/Qwen2.5-7B-Instruct \
  --dataset dog_control \
  --template qwen \
  --finetuning_type lora \
  --lora_target q_proj,k_proj,v_proj,o_proj \
  --lora_rank 8 \
  --lora_alpha 16 \
  --lora_dropout 0.05 \
  --output_dir /workspace/dog_llm_exec/output_qwen25_lora \
  --overwrite_output_dir \
  --cutoff_len 512 \
  --per_device_train_batch_size 4 \
  --per_device_eval_batch_size 4 \
  --gradient_accumulation_steps 4 \
  --learning_rate 2e-4 \
  --num_train_epochs 3.0 \
  --val_size 0.1 \
  --lr_scheduler_type cosine \
  --warmup_ratio 0.1 \
  --logging_steps 10 \
  --save_steps 100 \
  --eval_steps 100 \
  --evaluation_strategy steps \
  --plot_loss \
  --bf16
```

## 9. 本地 Ollama 部署

> Ollama 常规流程：先合并 LoRA -> 再转 GGUF -> 再 create。

## 9.1 合并 LoRA

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

base = "Qwen/Qwen2.5-7B-Instruct"
lora = "./output_qwen25_lora"
out = "./merged_qwen25_dog"

model = AutoModelForCausalLM.from_pretrained(base, trust_remote_code=True)
model = PeftModel.from_pretrained(model, lora)
model = model.merge_and_unload()
model.save_pretrained(out)

tok = AutoTokenizer.from_pretrained(base, trust_remote_code=True)
tok.save_pretrained(out)
print("merged ->", out)
```

## 9.2 转 GGUF（llama.cpp）

```bash
git clone https://github.com/ggerganov/llama.cpp.git
cd llama.cpp
pip install -r requirements.txt

python convert_hf_to_gguf.py /path/to/merged_qwen25_dog --outfile /path/to/qwen25_dog.gguf
./quantize /path/to/qwen25_dog.gguf /path/to/qwen25_dog_q4_k_m.gguf q4_k_m
```

## 9.3 创建 Ollama 模型

`Modelfile`：

```txt
FROM /path/to/qwen25_dog_q4_k_m.gguf

SYSTEM 你是机器狗控制指令助手。必须只输出JSON：{"actions":[...]}，不要解释。

PARAMETER temperature 0.1
PARAMETER top_p 0.9
PARAMETER num_ctx 4096
```

执行：

```bash
ollama create dog-control-qwen25 -f Modelfile
ollama run dog-control-qwen25
```
